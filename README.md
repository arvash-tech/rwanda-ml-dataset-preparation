# Machine Learning Dataset Preparation — Rwanda

## Project Overview

This project is part of the Rwanda Polytechnic Kigali College Machine Learning practical assignment: **Two Rwandan Scenarios: Build Machine-Learning-Ready Datasets**.

The objective is to prepare two datasets suitable for future Machine Learning tasks through data inspection, cleaning, preprocessing, visualization, and documentation.

## Project Scenarios

### Question 1: Rwanda Maize Yield

Prepare the provided `maize_yield_rwanda_raw.csv` dataset for Machine Learning.

**Status:** Awaiting the original dataset from the lecturer.

### Question 2: Rwandan Scenario

Develop a second Rwandan dataset with at least 1,000 records and 8 features, subject to lecturer approval.

**Status:** Scenario selection and approval pending.

## Environment Setup

1. Install Anaconda.
2. Clone this repository.
3. Run `conda env create -f environment.yml`.
4. Activate the environment using `conda activate ml-project`.
5. Launch Jupyter Notebook using `jupyter notebook`.
